Privacy Policy

Application: Annie (her-os personal) · Last updated: 28 June 2026

Annie (her-os personal) is a private, single-user personal assistant operated by an individual for their own use. It connects to the WHOOP API, with the account holder's explicit authorization, to read that same individual's own WHOOP data so the assistant can provide them personal wellness insights. This application is not a commercial product, has no other users, and does not offer accounts to anyone else.

1. What data is accessed

With the scopes you grant during WHOOP's OAuth consent, the application may read your:

  • Recovery data (including heart-rate variability and resting heart rate)
  • Sleep data
  • Physiological cycles and strain
  • Workouts
  • Basic profile and body-measurement data

It reads this data only. It does not write to, modify, or delete anything in your WHOOP account.

2. How the data is used

Solely to give the account holder personal, informational wellness insights (for example, summarizing trends in sleep and recovery). The data is not used for advertising, profiling for third parties, training public models, or any commercial purpose.

3. How the data is stored and protected

  • Data is stored privately on the account holder's own personal server infrastructure.
  • OAuth tokens are kept in access-restricted storage and are never embedded in shared code or logs.
  • The data is never sold, and is not shared with any third party.

4. Data retention and deletion

Data is retained only as long as it is useful to the account holder, who may delete the locally stored data at any time. Because this is a personal application, the account holder is also the only data subject.

5. Revoking access

You can revoke this application's access to your WHOOP data at any time from your WHOOP account's connected-apps / developer settings. Revoking access stops all further data retrieval immediately.

6. Not medical advice

This application provides general wellness information only. It is not a medical device and does not diagnose, treat, cure, or prevent any condition. It is not a substitute for professional medical advice; consult a qualified clinician for any health concern.

7. Contact

For any question about this policy or the data handled by this application, contact the operator at my_identity@mac.com.

This policy covers a personal, non-commercial integration built on the WHOOP API. Use of WHOOP data is additionally governed by WHOOP's own terms and privacy policy.
